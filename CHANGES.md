# CHANGES

Незакоммиченные изменения (файл очищается после коммита).

## Инициализация репозитория и оформление проекта

- Инициализирован Git-репозиторий (ветка `main`).
- Добавлен `.gitignore` (игнорируются `tmp/` и `context-debug.log`).
- Добавлен тестовый конфиг проекта `opencode.json`: провайдер `LocalAI`
  (OpenAI-совместимый, `aisdk:@ai-sdk/openai-compatible`) и
  `"plugins": ["./plugin"]`, модель `Qwen3-Coder` без `limit` —
  чтобы автоопределение контекста работало.
- Добавлен `install.bat` — установка плагина в глобальный каталог
  `%USERPROFILE%\.config\opencode\plugins\localai-context\`.
- Добавлен `AGENTS.md` — описание архитектуры, потоков данных и зависимостей.
- Добавлен `LICENSE` (MIT).
- Полностью переписан `README.md` по образцу репозиториев
  AITranslator / VoiceTranslator_Telegram:
  - описание, возможности, требования;
  - несколько способов установки (CLI, `install.bat`, вручную, project-local);
  - готовый промт для OpenCode, устанавливающий плагин автоматически;
  - описание переменных окружения и настроек;
  - проверка работоспособности, обновление, удаление.
